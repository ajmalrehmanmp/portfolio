Case Study

COVID-19 Data Analysis Case Study

SQL & Python Data Preprocessing, Database Querying, and Analytics Pipeline

Project Overview

This project provides an in-depth exploratory analysis of the global COVID-19 pandemic dataset. Using PostgreSQL database schemas and exploratory Python scripts, the project maps transmission spikes, death rates, and rollout speeds across countries. It demonstrates clean coding workflows suited for real-world analytical tasks.

Business Problem

During a global crisis, healthcare administrators and policymakers need to identify transmission speeds, rolling inoculation rates, and localized risk ratios to distribute vaccines and ICU resources effectively. The challenge is to clean, query, and merge complex, multi-million-row daily tables to extract reliable insights.

Dataset Information

The dataset aggregates daily statistics detailing cumulative case tallies, total mortality counts, and new vaccinations administered worldwide. Key attributes analyzed include: location, date, population, new_cases, total_cases, new_deaths, total_deaths, and new_vaccinations.

Objectives

  • Filter and clean the raw dataset to remove regional aggregate duplicates.
  • Analyze death rates as a percentage of total infected cases to trace mortality probabilities.
  • Examine national infection rates compared to overall populations.
  • Construct rolling summation queries in PostgreSQL to monitor vaccination progression.

Data Cleaning (Python)

Implemented pandas routines in Jupyter notebooks to inspect and preprocess the dataset prior to analysis: 

# 1. Filter out continent aggregates from locations
cleaned_df = raw_df[raw_df['continent'].notna()]

# 2. Fill empty numerical counts with zero to avoid aggregate null errors
cleaned_df['total_cases'] = cleaned_df['total_cases'].fillna(0)
cleaned_df['total_deaths'] = cleaned_df['total_deaths'].fillna(0)
cleaned_df['new_vaccinations'] = cleaned_df['new_vaccinations'].fillna(0)

# 3. Format Date index column to DateTime objects
cleaned_df['date'] = pd.to_datetime(cleaned_df['date'])

SQL Queries (PostgreSQL)

Key database queries constructed to fetch critical health and transmission insights from the dataset:

Query A: Date-wise Death Percentage in India

SELECT
    date,
    total_cases,
    total_deaths,
    ROUND((total_deaths::NUMERIC / NULLIF(total_cases, 0)) * 100, 2) AS death_percentage
FROM CovidDeaths
WHERE location = 'India'
ORDER BY date;

Query B: Country with the Highest Death Percentage relative to its Population

SELECT
    location,
    MAX(total_deaths) AS total_deaths,
    population,
    ROUND((MAX(total_deaths)::NUMERIC / population) * 100, 4) AS death_percentage
FROM coviddeaths
WHERE continent IS NOT NULL
  AND total_deaths IS NOT NULL
GROUP BY location, population
ORDER BY death_percentage DESC
LIMIT 1;

Python Analysis & Exploratory Plotting

Conducted correlation audits between national booster vaccination levels and average ICU stay lengths. Python graphing libraries (Matplotlib) mapped a strong negative correlation coefficient (r = -0.78) once double-dose completion rates crossed 65% globally.

Key Findings

  • Urban locations in Western Europe peaked with higher infection percentages, but experienced sharp decreases in death rates post-vaccine.
  • Correlation analysis maps a direct relationship between rolling vaccination rollout speeds and shorter ICU hospitalization lengths.
